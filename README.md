# Shah Hussain — Marriage Biodata

A modern, interactive marriage biodata web application built with React, TypeScript, Tailwind CSS, React Lenis, and multi-layered Parallax effects.

## ✨ Features

- **Islamic Luxury Theme**: Emerald & Gold palette with Arabic calligraphy and subtle ambient stardust particle physics.
- **Buttery Smooth Momentum Scroll**: Powered by `lenis/react` with frame-synchronized parallax depth layers.
- **Interactive Photo Showcase**: Dual-row opposite-direction infinite marquee with tap-to-expand lightbox modal and auto-cycling hero carousel.
- **Comprehensive Profile Sections**: Detailed background covering Personal Details, Education, Professional Career, Family, and Contact Channels.
- **Fully Responsive**: Mobile-first design with bottom navigation drawer and desktop floating glassmorphism header.

## 🛠 Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Vanilla CSS Variables
- **Smooth Scroll**: Lenis (`lenis/react`)
- **Icons**: Lucide React
- **UI Components**: Radix UI + shadcn/ui

## 🚀 Getting Started

```bash
# Install dependencies
npm install --legacy-peer-deps

# Start local dev server
npm run dev

# Build for production
npm run build
```
